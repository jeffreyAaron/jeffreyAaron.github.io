### Part 2: Conditional Generation and Guidance

#### 2.1 Classifier-Free Guidance

Guidance weight w = 7, prompt: "a high quality photo"

The classifier free guidance greately improves the realism of the image. However, it also reduces the diveristy of the output. The trend seems to be humans (although this model is capable of generating other objects).

```python
def cfg_velocity(x, t, condition, w, predict_velocity, null_condition=''):
    v_c = predict_velocity(x, t, condition)
    v_u = predict_velocity(x, t, null_condition)
    return v_c + w * (v_c - v_u)
```

```python
def visual_anagrams(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def anagramVelocity(x, t):
      v1 = cfg_velocity(x, t, condition_a, w, predict_velocity, null_condition)
      v2 = rotate180(cfg_velocity(rotate180(x), t, condition_b, w, predict_velocity, null_condition))
      v = (v1 + v2)/2
      return v
    x_out, frames = euler_sample(noise, 0, step_size, anagramVelocity)
```

#### 3.4 Hybrid Images

Similar to the hybrid images in the previous project, having high frequency prompts as the large image and low frequency prompts as the small image was ideal for the best results.

```python
def make_hybrids(noise, condition_a, condition_b, predict_velocity, w=7, step_size=0.02):
    def hybridVelocity(x, t):
        v1 = cfg_velocity(x, t, condition_a, w, predict_velocity, null_condition)
        v2 = cfg_velocity(x, t, condition_b, w, predict_velocity, null_condition)
        # guassian blur kernel
        v1_low = lowpass(v1)
        v2_low = lowpass(v2)
        v2_high = v2 - v2_low
        v = v1_low + v2_high
        return v
    x_out, frames = euler_sample(noise, 0, step_size, hybridVelocity)
    return x_out #, frames
```

### Part 1: Training a Single-Step Denoising UNet

#### 1.1 Implementing the UNet

I followed the given implementation to setup the following layers.

```python
a = self.conv1(x)
b = self.down1(a)
c = self.down2(b)
d = self.flatten(c)

e = self.unflatten(d)
e = self.up1(torch.cat([e, c], dim = 1))
e = self.up2(torch.cat([e, b], dim = 1))
```

##### 1.2.3 Denoising Pure Noise

One step denoising for pure noise essentially caused the model to average all the outputs. ### Part 2: Training a Flow Matching Model

#### 2.1 Adding Time Conditioning to UNet

To help the model to learn to actually denoise, it needs to be fed images at different noise levels and expect to return a slightly less noised version of it. This is done by adding time as a condition which tells the model which stage its in. If the model is at t = 0.9 (very little noise), the model will learn not to make large adjustments.

#### 2.2 Training the UNet

```python
noise = torch.randn_like(x_1)
t = torch.rand(x_1.shape[0], device=x_1.device)

x_t = torch.zeros_like(x_1)
for i in range(x_1.shape[0]):
  x_t[i] = (1-t[i]) * noise[i] + t[i] * x_1[i]
pred = unet(x_t, t)
loss = nn.MSELoss()(pred, x_1 - noise)
```
