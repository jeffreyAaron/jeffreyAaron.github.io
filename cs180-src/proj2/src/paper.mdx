## Part 1: Fun with Filters

### Part 1.1: Convolutions from scratch

To hand code the convolution function, I started out by writing a function called `conv2d` for the four for loop case. First I flip the kernel and then pad the input image by one less than kernel height/width to ensure that the kernel is within bounds when we scan across the whole image. Because I chose to implement the function with full padding, the size of output image is the size of the original image plus the size of the kernel minus one.

Then for verification, I ensured that the difference between my func and scipy's function was under a very low threshold.
I did this using this operation: `np.abs(mine - ref).max()`

#### Convolution with four for loops

```python
# implemented with full padding
def conv2d(image, kernel):
    kHeight, kWidth = kernel.shape
    height, width = image.shape
    height = height + kHeight - 1
    width = width + kWidth - 1
    image = np.pad(image, ((kHeight-1, kHeight-1), (kWidth-1, kWidth-1)))
    kernel = np.flip(kernel)
    outputImage = np.zeros((height, width))
    for r in range(height):
        for c in range(width):
            output = 0
            for kr in range(kHeight):
                for kc in range(kWidth):
                    kernel_value = kernel[kr][kc]
                    output += kernel_value * image[r + kr][c + kc]

            outputImage[r][c] = output

    return outputImage
```

#### Convolution with two for loops

```python
# two for loops version
def conv2d_optimized(image, kernel):
    kHeight, kWidth = kernel.shape
    height, width = image.shape
    height = height + kHeight - 1
    width = width + kWidth - 1
    image = np.pad(image, ((kHeight-1, kHeight-1), (kWidth-1, kWidth-1)))
    kernel = np.flip(kernel)
    outputImage = np.zeros((height, width))
    for r in range(height):
        for c in range(width):
            outputImage[r][c] = np.sum(image[r:r+kHeight, c:c+kWidth] * kernel)

    return outputImage
```

#### Boundaries

In regards to the boundaries of the image, I zero fill the padded edges of the images. I also use full padding which outputs an image that every kernel position contains at least one pixel from the source image. This matches the behavior of scipy's convolve2d if you set the params `boundary='fill', fillvalue=0, mode='full'`

#### Performance

```text
image shape: (605, 454)
four for loop (s): 8.5484
two for loop (s): 0.5539
scipy time (s): 0.0257
```

For the image of myself, the scipy implementation was 21 times faster than the 2 for loop implementation and roughly 300x faster than the 4 for loop implementation. It is surprising how much faster the 2 loop implementation performs over the 4 loop. I think this is because the 4 loop implementation needs to sweep over 2 extra dimensions (the kernel). For a kernel of 9x9, this is 81x more iterations.

I applied the finite difference operator using the `convolve2d` function from `scipy.signal`. I chose to use the `boundary='symm'` option to prevent strong lines and thresholding at the edge of the image. The partial derivatives in x and y are computed using the kernels Dx and Dy. The gradient magnitude is the sqrt of the sum of the squares of the convolution Dx and Dy. The binarized edge image is obtained by applying a threshold to the gradient magnitude.

### Part 1.3: Derivative of Gaussian (DoG) filter

I followed the instructions to create the weighted Gaussian kernel by first creating a 1D version and then using outer product to build the whole kernel. My kernel is 5x5.

```python
# create gaussian kernel

gaussianKernel1d = cv2.getGaussianKernel(5, 1.0)
gaussianKernel2d = gaussianKernel1d @ gaussianKernel1d.T
```

#### Derivative of Gaussian (DoG) filters

The DoG filters are a combination of the Gaussian kernel convolved with the Dx and Dy derivative kernels.
Instead of applying two filters in sequence, we can first apply the Dx kernel to the Gaussian kernel as convolution is associative. So image * Gaussian * Dx is the same as image * (Gaussian * Dx).

```python
dog_kernel_x = scipy.signal.convolve2d(gaussianKernel2d, Dx, mode='full')
dog_kernel_y = scipy.signal.convolve2d(gaussianKernel2d, Dy, mode='full')
```

#### Verifying that one convolution matches two

I tried both approaches of applying the convolutions individually (image * Gaussian * Dx) and by using the DoG kernel (Gaussian * Dx). The results are identical. I used mode='full' to preserve all the information when creating the DoG kernel. Without this, the kernel size would be 5x5 and this would cut off some low value rows. It may not be noticeable visibly, but it will make a difference numerically.

### Part 2.1: Image sharpening

<Figure>
  <Picture slot="figure" src={blurryFriends} alt="A blurry photo of my friends" />
  <span slot="caption">The blurry photo of my friends</span>
</Figure>

In order to sharpen the images, we can use the method described in class by blurring the image (applying a low pass filter) and then subtracting the blurred image from the original image. This difference leaves us with the details in the image. Then we can add this difference back to the original image by a factor. This ends up adding more details to the image.

Because the image of my friend was very blurry, I found that applying two filters with two different kernel sizes helped to enhance the details. I found that the different kernel sizes target different levels of blur.

### Part 2.2: Hybrid images

In order to create the hybrid images, we are essentially taking two images that ideally have different frequency bands. For the high frequnecy image, we remove the low frequency componenent by subtracting a blurred image from the initial image (high pass). For the low frequency image, we blur the image to remove the high frequency components (low pass). Then we add the two images together to create a hybrid image.
