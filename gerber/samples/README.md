# Sample boards

Gerbers exported from [Cynthion](https://github.com/greatscottgadgets/cynthion-hardware) by Great Scott
Gadgets, used under the CERN Open Hardware Licence v2 – Permissive (see `LICENSE-cynthion`).

- `cynthion-prev/`: commit 7a39520
- `cynthion/`: commit 2dd8576 "Clean up layout" (inner zone tweaks, via sizes, diodes nudged)

`sonicsurface/`: SonicSurface 1.2 (2 layers, 183 × 169 mm) by [UpnaLab](https://github.com/upnalab/SonicSurface), a 16 × 16
array of 10 mm ultrasonic transducers, used under the MIT licence (see `LICENSE-sonicsurface`). These are its
Altium Gerber and drill outputs (copper, silk, outline, NC drill).

These are only served by the dev server (`npm run dev`) for the Gerber viewer; they aren't part of the
built site.
