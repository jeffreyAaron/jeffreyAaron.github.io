1.2 Classical Denoising

Classical denoising used different gaussian levels to blur out the noise. This wasn’t very effective and still left grainy images.

1.3 One-Step Denoising

The flow model does much better at reducing noise, however with only one step, it removes a lot of detail as it has to make a large guess of what the target is.

1.4 Visualizing Velocity

Intuitiely, starting from a more noisy image results in more error in the final output. I did notice that error is more noticable in the grass texture where there are higher freq details.

1.2.2 Out-of-Distribution Testing

The results above show that the model works fine under the sigma level that we trained the model on simga = 0.5. However, we also want to see how it performs for other noise levels. As the noise was increased above 0.5, the model struggled to recreate the number perfectly and had some artifacts. Below 0.5, the model didn’t show any significant difference.

1.2.3 Denoising Pure Noise

One step denoising for pure noise essentially caused the model to average all the outputs. Since the model has to guess from pure noise to a number in one step, the model maps the same start point to many endpoints. The loss optimizes the model to average all the MNIST numbers. From epoch 1 and epoch 5, the only difference I notice is that the epoch 1 results are more grainy.

Part 2: Training a Flow Matching Model

2.1 Adding Time Conditioning to UNet

To help the model to learn to actually denoise, it needs to be fed images at different noise levels and expect to return a slightly less noised version of it. This is done by adding time as a condition which tells the model which stage its in. If the model is at t = 0.9 (very little noise), the model will learn not to make large adjustments.

Here we add classes to the UNet. However, to me, this feels a little like cheating at the model could very easily memorize the dataset.

2.5 Training the UNet

For training, I tried two different approaches, a scheduled learner that starts at 1e-2 and then dropped down to roughly 1e-3. The other option was to maintain a fixed 1e-3 learning rate. From the training curves and the outputs, both produced similar results. Because the scheduled version decays, it needs a higher starting learning rate than the constant version.
